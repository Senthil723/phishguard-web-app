# PhishGuard frontend

The React frontend provides login, URL scanning, results, history, settings, and reports. See the [project README](../README.md) for full setup.

From this directory, run `npm install`, copy `.env.example` to `.env`, and run `npm run dev`. The example API URL uses `localhost`; keep the same hostname for the frontend and API during local development so session cookies work.

Run `npm run lint` and `npm run build` before release.
